# PGLife_Full_Stack_Project-
PG Life – PG Accommodation Finder

PG Life is a web-based accommodation platform developed as part of the Internshala Web Development Training Project. It helps students and working professionals find suitable Paying Guest (PG) accommodations in different cities.

The platform allows users to explore PG properties, view accommodation details, and find suitable places to stay based on their preferences.

 # Features

- Browse PG accommodations in different cities.
- View detailed information about PG properties.
- Explore property images and amenities.
- User registration and login functionality.
- Search and explore available accommodations.
- Responsive and user-friendly interface.
- Property details with rent, gender preferences, and facilities.
